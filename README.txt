Nk Top-up Np website (QR payment version)

Files:
- index.html: responsive website
- esewa-qr.jpg: the eSewa QR image provided by the owner
- khalti-qr.jpg: the Khalti QR image provided by the owner

How to publish for free:
1. Create/sign in to a GitHub account.
2. Create a repository and upload all four files into the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.

Payment flow:
- Customer selects service/package, sees the listed price, and continues to WhatsApp with order details.
- Customer scans the selected eSewa or Khalti QR and pays after verifying the recipient and amount.
- Customer sends transaction reference and payment screenshot in WhatsApp.
- The owner checks payment manually before delivering the service.

Important:
This is a static website. It does not process payments, receive screenshot uploads directly, automatically verify transactions, store orders in a database, or automatically deliver game credits. Do not mark an order paid until you verify the transaction in your payment account. Never ask customers for their PIN, OTP, or password.
